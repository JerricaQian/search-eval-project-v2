# 页面与结果卡轻量识别规则

## 1. 事实优先级

当前截图的本地像素、OCR 原文和本图拓扑最高；其次为 `card_recognition_contracts.v1.json`、页面/卡型 taxonomy 和清洗后的几何分布。黄金 JSON、历史场景、文件名、历史模板和其他截图不得补造当前事实。

Phase2 不依据 OCR 置信度发布字段，不生成体验结论。本地 CV/OCR 后必须用视觉模型复核当前图片的全部活动元素和漏标；模型只可读取当前像素，不得从黄金 JSON 或语言常识补值。无法通过门控的事实保留在该截图主 JSON 的阻断和重跑目标中。

## 2. 页面顺序

先识别搜索栏、Tab、可选提示/图筛/文筛/业务图筛/主点卡/运营卡、排序筛选、可选优惠筛选，最后识别结果列表。普通连续结果只登记一个 `results_list`。

图筛、运营卡、主点卡和悬浮服务不能成为普通结果卡种子。续屏只登记当前可见模块，不从首屏复制 Tab 或筛选组件。

## 3. 卡型状态机

1. 对每个稳定卡边界计算结构、媒体和文本证据。
2. 已知卡型必须满足全部 `minimumEvidenceGroups` 且不命中 `forbiddenFeatures`。
3. 多个已知卡型通过时才选择最接近者。
4. 无已知卡型通过且存在明确广告标时归广告卡。
5. 其他稳定独立渲染单元归异构卡；禁止输出 `unknown`。

人工黄金卡型只在推理完成后对照，不能成为分类输入。几何经验只是软证据，不能补齐价格、媒体或商家指标。

## 4. 不同卡型的边界

- 商品卡：单商品主图、标题和价格形成同列重复卡。
- 商家图文下挂：商家头图吸附下一商家头图前的右侧商品图片组。
- 商家文字下挂：商家主体吸附下一商家头图前的纯文字服务块。
- 酒店：单列按本卡头图/标题锚至下一同列锚切分；双列按独立网格单元逐格切分，不跨列吸附。头图高度按当前卡像素量取，不固定。
- 演出：以竖版海报和演出身份切分。
- 电影：以影院标题和场次块切分。
- 度假/酒店套餐：主图、套餐概要和价格保持同一卡。
- 主点卡：位于普通结果列表前，不占结果 `listPosition`。

当前截图至少有两个稳定重复卡时，可用本图周期回填至多一个漏检的前置卡；不得使用黄金坐标或期望数量。

query 不是结构证据。同一 query 的两次搜索结果可以完全不同；混排页必须保持逐卡边界和逐卡类型。双列页尾自然截断卡只从同列上一卡继承。

## 5. 页尾自然截断

结果流最后一张重复卡自然触及屏幕底边时，若上一张已确认具体已知卡型且当前卡没有广告证据，可继承上一张卡型。只豁免截图外不可见的必需字段和语义锚点；当前可见文字的乱码、字段文法错误和双版面分歧仍阻断整页。

## 6. 文本与语义

默认使用 Tesseract PSM 6/11 双版面。自然文本允许确定性包含或高相似一致；价格、评分、距离等结构字段要求数值锚一致。语言纠错候选只能触发重跑，不能改写 `rawText`。

页面文本角色不能仅因包含一个短结构词覆盖卡片区域角色。例如长标题尾部带“35分钟”，整行仍是标题；距离必须整行匹配距离形态，履约/评分/销量必须由短结构字段主导。

## 7. 最小元素与 Phase3 事实

每个确认元素记录 `id`、所属组件、元素类型、原文/简述、坐标、排除状态和 `render`。文字另记 `textFacts`；标签/icon 与可判实体另记 `visual`。

标签、角标、腰封、券标和 icon 必须逐个拆分。当前阶段不做通用圆角容器检测；没有像素证据时 `containerShape=unknown`。图片记录准确坐标与 `isPhoto=true`；组件与页面综合色数由 Phase3 读取非图片 UI 元素的已确认 JSON 颜色角色后去重计算。

## 8. 整页发布门控

任一卡型未确认、最小契约不满足、可用文字不足、无语义锚点，或任一字段文法/连贯性/双版面一致性/碎片/卡型语义 hook 失败时，整页 `phase3Ready=false`。允许只重跑失败卡或失败行，但重跑后必须再次执行整页门控；禁止部分页面提前进入 Phase3。

## 9. 一图一 JSON

每张截图独占一个主 `elements.json`，包含页面全部可见模块、卡片、最小元素和门控状态。多个截图不得合并到同一 JSON。批量 `index.json` 仅索引各自 `canonicalManifest` 和回归指标。
