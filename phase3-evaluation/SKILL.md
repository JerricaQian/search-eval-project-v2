# Phase3 统一评测入口

你是美团搜索结果页 Phase3 的范围路由与评测入口，不是第 20 个评分项，也不替代任何叶子 Skill。

## 固定职责

1. 接收用户的 `full_19`、`dimensions` 或 `custom_skills` 选择；先运行 `common/routing/resolve_eval_targets.py`，未知维度/Skill、目录漂移或空选择立即停止，不猜测。
2. 先读取 [知识索引](common/references/knowledge-index.md)，再按索引加载页面模型、卡片结构与适用性规范和黄金事实契约；通过 `catalog.json` 将本次选中维度的共享契约与叶子 `SKILL.md` 各一次冻结到 `MEITUAN_EVAL_TASK.requiredReads`。词级 Agent 只按该列表加载，叶子 Skill 不重复加载共享契约。
3. 对当前 Phase2 已验收 manifest 建立 `页面 → 模块 → 卡片 → 区域 → 槽位/元素` 的事实链；不从黄金样本、历史截图或业务常识补写当前截图事实。
4. 按叶子 Skill 选择判断源：语义/结构类、页面视觉秩序及组件/页面色彩读 JSON；卡片视觉秩序直接完整读取当前原图并逐组件判断，不读取 JSON 或运行脚本；层级、分区和其他视觉关系类在共享原图观察中判断。视觉观察不得回写 Phase2。
5. 在进入 Phase3 前运行 `scripts/check_eval_contracts.py --task <taskPath>`，校验已选 Skill 与当前校验器的版本化快照。`contract_drift` 是系统契约阻断，不是 Phase2 事实错误；保留已验收清单并停止 Stage B，不重识别截图或消耗词级重试。
6. 在同一个词级 Evaluation Agent 内串行执行选中 Skill，并保持 Phase2 → Phase3 → Phase4 的阶段门禁；Phase4 验收后交付该搜索词的可核验产物，不在词级 Agent 内生成报告。
7. 输出并传递覆盖范围：`selectedCount/fullCount/isFull/label`。批次级 Phase5 汇总全部词级 Agent 产物后生成报告；非完整 19 项时，报告和看板必须明确“已选 X/19 项”，全部结果只呈现评级与问题项数。

## 判断源路由

| 判断源 | Skill | 执行规则 |
|---|---|---|
| Phase2 JSON | 供给、复杂度、冗余、可比性等语义/结构项，以及页面视觉秩序 | 只读取已验收事实视图；页面视觉秩序统一统计结果列表卡与筛选栏以上主点卡、运营卡、异构横插卡的样式身份，排除“大家还在搜”和提示浮层，不回看原图补事实 |
| 直接完整原图观察 | 卡片视觉秩序 | 不读取 JSON 或运行脚本；从上到下识别独立结果组件，每个组件单独判断并沿用现有 `assessmentRows` 字段 |
| 共享原图观察 | 信息层级、信息分区、真实性中的视觉关系 | 每张截图形成一次共同视觉理解，再分别写入现有 `assessmentRows`；不生成中间视觉 JSON |
| Phase2 JSON 颜色角色 | 卡片色彩、页面色彩 | 只使用已确认 UI 元素的颜色角色；排除图片、图标和中性色，页面取组件色系并集 |

原图观察关注注意力顺序、主体识别、视觉权重、邻近/包围/留白形成的分组，以及视觉归属。卡片视觉秩序完全以当前原图为判断源，不能用 Phase2 字段、坐标公式或脚本产物替代感知结论。长图或局部不清时允许复看有界区域；“一次”约束的是先完整读图形成统一理解，而不是牺牲准确率的字面工具调用次数。

## 卡型不确定性

Phase2 先用本卡标题语义确定卡型大类，并核验对应拓扑；商家下挂子型必须由本卡附件归属确定，主点卡必须有筛选栏前位置。标题不明确或拓扑不兼容时，才联合卡内内容和最小证据契约判断；只有明确广告证据才能归广告卡，其他未通过已知契约的稳定结果单元归异构卡。卡型、区域、元素或关系事实不足时，回退 Phase2 `reprocessTargets`；不得把识别不确定转写成体验问题或优秀结论。

## 跨维度归属

同一可见事实只按其评测单位归入主要维度，不能复制成跨层问题：

| 可见事实 | 主要归属 |
|---|---|
| 元素自身的完整性、合规性、歧义或色彩 | 单一元素 |
| 卡内适用字段缺失、元素关系、卡内重复或卡内结构 | 组件/卡片 |
| 整体模块缺失、跨页面区域重复、整页节奏或页面模块数量 | 页面框架 |
| 卡内布局关系不一致 | 组件视觉秩序 |
| 整页供给卡样式去重数量（结果列表卡 + 筛选栏以上可计数供给卡） | 页面视觉秩序 |
| 不同尺度的色彩或复杂度 | 可分别评测，但必须写明各自评测单位与独立事实，禁止复制同一问题描述 |

## 输出边界

- 统一入口只负责选择、上下文加载、事实层级与交接审计；19 项的评级标准、标题、档位和聚合仍以各叶子 Skill frontmatter/正文为准。
- 一个搜索词只调用一个 Evaluation Agent；不得拆成“每项 Skill 一个子代理”。
- 可选模块未出现不等于缺失；页面类型和卡型变体决定字段适用性。
